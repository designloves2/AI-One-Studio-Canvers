# Director Mode — 한꺼번에 검증할 목록 (코드·UI 는 끝났고, 아래는 아직 안 돌려 본 것)

규칙: 시험 포트는 8766 (운영 8765 금지). 데모 시험은 `window.__directorLlm = window.__directorDemo` 또는 "LLM 없이 체험해 보기". 실제 LLM·GPU 시험은 사용자가 "서버가 비었다"고 한 뒤에만(`nvidia-smi`, `GET /queue` 확인). 시험 중 소스 수정 금지(hot reload 가 데모 플래그를 풀 수 있음). HMR 뒤에는 콘솔 import 가 다른 인스턴스가 되므로 화면 버튼으로 확인.

## A. 데모(LLM·GPU 불필요)
1. 뮤직비디오 문장 → 브리프 → 캐스팅 → 노래 → 시나리오 → 편 작성 → 캔버스 → 생성 → 검토 → 완료 (노래 단계까지는 확인함).
2. 노래: "내 노래" 선택 → 파일 올리기(데모는 짧은 효과음) → 구조 제안 → 구간 막대 → 승인.
3. 완성 영상 블록: 생성 단계에서 모든 클립 결과가 있으면 "클립을 합치고 노래 넣기" → 카드 이미지가 완성본으로 뜨는지.
4. 채팅으로 "AI로 노래 만들어줘" → `music.source=generate` 로 바뀌고 `music.generate` 이면 생성 확인창.
5. 광고·브이로그·숏폼: 브이로그 클립의 "내레이션" 라벨, 1편짜리 종류의 자동 작성.
6. 좁은 창(<900px): 채팅이 아래로 쌓이고 단계 줄·회차 줄이 가로 스크롤 되는지.

## B. 실제 서버(사용자 OK 후)
1. 실제 LLM 으로 전체 흐름(브리프~편 작성). 로컬 GGUF 는 5분 넘으면 터진 것.
2. 캐스팅 이미지 실제 생성(모델별 파라미터 호환), 후보 이미지 줄, 갤러리 선택 에셋 등록.
3. 클립 생성: `@imageN` 순서와 `h3-ref` 엔진 연결, 생성 중 클립별 진행 막대.
4. 노래: 파일 업로드(`importFile`), Music Generate(acestep/yue2/minimax), 에셋 등록(category music).
5. 완성 영상: Video Stitch → Add Audio(노래 얹기) 실제 실행, `applyEpisodeFinal` 로 편에 들어오는지.
6. 결과 우클릭 → 에셋 등록: 영상·음악 결과, 새 이미지 신규 등록.
7. 캔버스 단계 "다른 화면비": 9:16·1:1 체크 → 캔버스 만들기 → 파일이 `… - ep01 - 9x16` 로 생기고 화면비가 바뀌었는지, 주 캔버스·생성 단계에 영향이 없는지(데모는 파일을 안 만듦).
8. 캐스팅 "+ 새 모습": 설명 입력 → 새 카드(`look of …`) 생기고 프롬프트에 설명이 붙는지, 생성·에셋 등록·클립 연결이 일반 항목처럼 되는지.
9. 새 모습을 기본 이미지가 있는 상태에서 만들 때: 캐스팅 캔버스에 `Image Edit` 카드 + `(base image)` Load Image 카드가 연결되는지, 결과가 같은 얼굴인지(실제 GPU).
10. 캐스트 이미지 선택창: 갤러리/라이브러리에서 눈가리기 한 그림이 흐리게 보이고, 헤더의 "전체 잠깐 보기"로 풀리는지.
11. 캐스팅: 채팅으로 "○○를 40대로 바꿔줘" → 카드 설명이 바로 바뀌는지(승인된 항목 포함), "이름을 ○○로" → 이름 변경이 시나리오·클립에도 따라가는지.
12. 캐스팅 생성: 캔버스 프롬프트 카드 = 설명 + "Full-body…" 안내, 이미지 카드의 Auto enhance 가 켜져 있고 실제로 모델별로 다시 쓰여 들어가는지(이미지 품질 비교). 카드에는 한 가지 언어만 보이는지.
13. 시나리오: 편 카드마다 인물·소품·장소 아바타(+이름)가 보이고 장소도 빠지지 않는지, 비면 "인물·소품 없음/장소 없음" 표시. 채팅으로 "3편에 ○○ 추가" 하면 바로 갱신되는지.
14. 편 작성: 시작 때 화면이 비어 있고(예전 장면 없음), 여러 편을 동시에 써도 각자 자기 편에만 들어가는지. 클립 출연자에 대사하는 사람이 모두 들어있는지, 장소가 모든 클립에 있는지.
15. 생성·확인: 클립마다 "합격"·"합친 영상에 넣기" 체크, 결과를 다시 만들면 합격이 풀리는지, 모두 합격이어야 "합치기"가 되는지, 하나 빼고 합치면 그 클립만 빠지고 순서가 맞는지(캔버스의 스티치 입력 선 확인). 드라마 등 모든 종류에서 스티치 카드가 생기는지.
16. 최종 검토: 합쳐진 영상을 보고 채팅으로 "3번 클립 어둡게" → 그 클립이 draft 로 돌아가고 편이 '생성·확인' 단계로 자동 복귀하는지, 승인하면 편이 끝나는지. 합친 영상이 없으면 승인이 막히는지.
